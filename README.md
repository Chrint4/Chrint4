### Projects
* **[Skin Studio](https://deltaskin-studio.vercel.app):** A browser-based editor for designing skins for the Delta emulator on iPhone. Lay out screens and buttons, swap in control packs, style the body with gradients, images or GPU-rendered procedural materials (WebGL fractal noise and domain warping), add stickers, and export a ready-to-install `.deltaskin`. Supports DS and GBA, including screens-only skins for game controllers.
* **Agricultural Workforce Management App:** My final-year university project, built with Flutter and Firebase for device/cloud syncing.
* **Mobile Dev:** Designing UI components for everyday utilities, including a Simple Notes App and a Calculator.
* **Game Development:** Frequent university hackathon and Game Jam participant. I've developed titles like *Grub Slayer* and *Ghosts Everywhere* using Godot and Object-Oriented Programming principles.
* **Scripting:** Built a YouTube Music Scraper using Python.
